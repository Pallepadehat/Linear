# 0004 — Better Auth for authentication

- **Status:** Accepted
- **Date:** 2026-10-29

## Context

We need email/password auth with secure sessions, owned by the API, usable from a Vue SPA.

## Decision

Better Auth in `apps/api` with the Drizzle adapter, mounted at `/api/auth/*`. Sessions are HTTP-only cookies. The app uses `better-auth/vue`. App and API are served same-origin (Vite proxy in dev, one domain in prod). Workspaces and membership are **our own tables**, not Better Auth's organization plugin, because they carry domain data (team keys, GitHub installations) and custom rules.

## Consequences

- No tokens in `localStorage`; CSRF protection via same-site cookies and Better Auth's origin checks.
- Auth tables are generated by Better Auth's CLI into `packages/db`.
- Adding OAuth (GitHub sign-in) later is a config change.

## Alternatives considered

- **Lucia** — deprecated as a library.
- **Better Auth organization plugin** — would duplicate or constrain our workspace model.
